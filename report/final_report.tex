\section{บทนำและวัตถุประสงค์}
รอยแตกกระดูกแบบเส้นผม (hairline / sub-millimetre fracture) มักตรวจพบได้ยากในภาพรังสีทั่วไป เนื่องจากความแตกต่าง
ของการดูดกลืนรังสี (attenuation) ที่รอยแตกสร้างขึ้นมีค่าน้อยมาก \textbf{สมมติฐานหลัก}คือรอยแตกทำให้เกิดการเปลี่ยนแปลง
เฉพาะจุดขององค์ประกอบการกระเจิงรังสี ซึ่งวัดผ่านอัตราส่วน
\[ \mathrm{SPR}(x,y)=\frac{I_{\text{scatter}}(x,y)}{I_{\text{primary}}(x,y)} \]
และอาจให้ ``ลายเซ็น'' ที่ตรวจจับได้ดีกว่าการดูดกลืนโดยตรง \textbf{วัตถุประสงค์ Phase 1:} ทดสอบว่าลายเซ็น SPR
จากรอยแตก (1)~ตรวจพบได้, (2)~ยืนยันเชิงสถิติ, (3)~ไม่ใช่ artifact, (4)~มีที่มาเชิงฟิสิกส์, (5)~ระบุขอบเขต ---
โดยใช้เพียงโมเดลที่มีอยู่ (รอยแตก 4 ขนาด) แล้วปรับพารามิเตอร์การรัน การทดสอบจัดเป็น 6 เสา (checklist CL-0…CL-7)

\subsection{Matched control --- ตัด confound ของ mesh (จุดสำคัญ)}
การเทียบโมเดล ``ปกติ'' กับ ``รอยแตก'' ที่เป็น\textbf{คนละ mesh กัน} ทำให้ $\Delta\mathrm{SPR}$ ถูกครอบงำด้วยความต่าง
ของ tessellation ทั้งก้อน จึงสร้าง \textbf{matched control} = mesh เดียวกับ fracture แต่ ``ถม'' ร่องด้วยกระดูก
(boolean union ผ่าน \code{manifold3d}) แต่ละตัวผ่านการตรวจสอบว่า control ตรงกับ fracture ทุกจุด\textbf{นอกร่อง}
(คลาดเคลื่อน 0.0000~มม.\ จากจุดยอด $>$349{,}000 จุด) $\Rightarrow$
$\Delta\mathrm{SPR}=\mathrm{SPR}_{\text{fracture}}-\mathrm{SPR}_{\text{control}}$ แยกเฉพาะผลของรอยแตก
คู่โมเดลและปริมาตรกระดูกที่ถมแสดงในตาราง~\ref{tab:models}

\subsection{Multi-seed significance + a-priori ROI}
รันซ้ำด้วยเมล็ดสุ่มอิสระ $N$ ชุด (control+fracture ใช้ seed เดียวกันต่อ realization = common random numbers)
แล้วทดสอบว่าค่าเฉลี่ย $\Delta\mathrm{SPR}$ ที่ ROI ต่างจาก 0 หรือไม่:
\[ t=\frac{\overline{\Delta\mathrm{SPR}}}{s/\sqrt{N}},\qquad \mathrm{df}=N-1;\qquad
   \text{s.e.}\propto\tfrac{1}{\sqrt{N_{\text{seeds}}}},\quad \text{MC noise}\propto\tfrac{1}{\sqrt{N_{\text{photons}}}} \]
กำหนด ROI 16$\times$16~พิกเซล ที่ตำแหน่งร่อง\textbf{ก่อนดูผล} (a-priori) เทียบ background ROil;
บีบลำแสง (collimation) เพื่อเพิ่มโฟตอน/พิกเซลที่บริเวณร่อง; ระบบงานทางไกล (job server + worker) กระจายงาน
แบบ multi-process ทำให้ทำ parameter sweep ได้อย่างเป็นระบบและทำซ้ำได้

% ================= 5. LIMITATIONS =================
\section{ข้อจำกัด (ระบุอย่างซื่อตรง)}
\begin{itemize}
  \item \textbf{ขอบเขตของ observable:} SPR ไวต่อ ``การมีอยู่'' แต่\textbf{อิ่มตัวเชิงความกว้าง}เกิน $\sim$0.5~มม.\ (CL-7)
        --- ไม่เหมาะกับการวัดขนาดรอยแตกใหญ่
  \item \textbf{สถิติของการทดสอบเชิงกลไก:} CL-3, CL-6 รันที่ $N=10$; ได้นัยสำคัญด้วยการวิเคราะห์ \textbf{within-seed}
        (CL-3 $p=0.002$; CL-6 $p=0.028$ marginal) แต่การประเมิน\textbf{ราย}พลังงาน/มุมเดี่ยวยัง noisy ---
        การยืนยันให้ robust (ไม่ marginal) ควรเพิ่มเป็น $N=20$--$30$
  \item \textbf{ขีดจำกัดเชิงเรขาคณิต:} มุมเอียงมาก (CL-6, $-30^\circ$) การเลื่อนวัตถุมากเกินทำให้เกิด artifact ---
        ต้องออกแบบการหมุนรอบจุดร่องโดยตรง
  \item \textbf{ความสมจริงของแบบจำลอง:} ฉากรับอุดมคติ (ไม่รวมประสิทธิภาพเชิงพลังงาน/จุดกระเจิงในฉากรับ),
        ลำแสง mono (ไม่ใช่สเปกตรัมจริง), รอยแตกตำแหน่ง/ทิศเดียว, ยังไม่เทียบกับข้อมูลภาพจริง
\end{itemize}

% ================= 6. CONCLUSIONS =================
\section{สรุปและงานถัดไป (Phase 2)}
Phase 1 ได้พัฒนา\textbf{ระเบียบวิธีที่ถูกต้อง} (matched control + multi-seed significance) ซึ่งเผยสัญญาณที่การเทียบ
แบบไร้เดียงสามองไม่เห็น และแสดง\textbf{หลักฐานเชิงประจักษ์}ว่าลายเซ็น SPR จากรอยแตกระดับต่ำกว่ามิลลิเมตรตรวจพบได้
อย่างมีนัยสำคัญ ยืนยันเชิงสถิติ ไม่ใช่ artifact และมีที่มาเชิงฟิสิกส์ --- เป็นฐานสำหรับ:
\begin{enumerate}
  \item \textbf{ยืนยันเชิงกลไกให้สมบูรณ์:} รัน CL-3/CL-6 ที่ $N=20$--$30$ + ช่วงมุมกว้างขึ้น (จนถึง tangential)
  \item \textbf{เพิ่มความสมจริง:} ฉากรับเชิงจริง, สเปกตรัมพลังงาน (kVp + filtration), การเทียบกับภาพจริง
  \item \textbf{ขยายขอบเขต:} ตำแหน่ง/ทิศทางรอยแตกอื่น, บริเวณกายวิภาคอื่น, optimization (พลังงาน, collimation,
        air-gap, ความละเอียด) เพื่อ CNR สูงสุด
\end{enumerate}
